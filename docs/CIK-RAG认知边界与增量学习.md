# CIK-RAG：知识冲突、选择性信任与增量学习

> 研究问题：当 RAG 检索到的知识互相冲突时，大模型何时值得相信、何时应该承认拿不准，以及什么情况必须交给人。

## 1. 这项扩展与原论文是什么关系

原论文的 DA（决策智能体）借鉴 SELF-RAG，采用“检索证据—自我批判—迭代精炼”三步流程，
并用相关性、支持性、实用性评分来选特征。这解决了“有没有检索证据”，但没有把以下情况
分开处理：

- 多个来源在**同一条件下给出相反结论**；
- 结论不同只是因为货币制度、预测期限或政策背景不同；
- 检索结果看起来一致，其实只是同一材料被多次转载；
- 特征有经济学解释，但样本外没有稳定预测价值；
- 平均效果为正，但统计区间跨过 0，模型其实拿不准。

原论文 PDF 的正式未来工作是：引入跨市场及其他异构实时数据、研究 API 延迟和大模型
计算开销、扩展到其他主要货币对。本文档的 CIK-RAG 是沿着论文 DA/SELF-RAG 机制继续
推进的研究扩展，不能写成原论文已经提出或验证过的方法。

## 2. 用《小马过河》理解算法

老牛说水浅，松鼠说水深，不能立刻做“二比一投票”。机器要先问四件事：

1. **说的是同一条河、同一水位和同一过河位置吗？** 条件不同，不是真矛盾。
2. **两句话是否来自独立来源？** 十篇转载仍然只是一份证据。
3. **说话者在当前问题上可靠吗？** 官方原文、同行评审、内部笔记权重不同。
4. **过去真的走成功过吗？** 金融中就是严格时间隔离后的样本外预测增益。

最后不强迫模型给出“过”或“不过”。它可以输出：自动采纳、自动拒绝、人工复核、
仅供研究、数据不足。这里的“拒答”是一种正式决策，不是系统故障。

## 3. 一个金融例子

问题是“美元指数上升是否应作为 USD/CNY 上升的预测特征”。知识库可能检索到：

- 论文 A：正常市场下，美元走强通常伴随 USD/CNY 上升；
- 报告 B：资本管制较强时期，这种关系显著减弱；
- 新闻 C：转载论文 A 的摘要；
- 研究 D：同一制度和期限下，美元指数没有预测价值。

算法会把 A 与 B 标成 `conditionally_differs`，因为制度条件不同；C 与 A 去重；A 与 D
在条件完全对齐后才标成 `contradicts`。然后再检查美元指数在 2020、2021、2022 三个
样本外折中是否真正降低了 20 日预测误差。

## 4. 算法构造

### 4.1 原子观点与来源

每篇材料先拆成可核查的原子观点：

```text
(特征, 影响方向, 币种, 预测期限, 市场制度, 政策条件,
 样本期, 来源类型, 发布时间, 有效期, 原文片段)
```

发布时间必须早于预测时点。未来才发表的研究不能解释过去的预测；缺少原文片段的观点
不能进入自动决策。

### 4.2 证据质量

对观点 i 的可靠质量使用几何平均：

\[
r_i=\left(\prod_{k=1}^{9} q_{ik}\right)^{1/9}
\]

九个分量包括来源权威性、证据类型、研究方法、样本量是否可查、时效性、有效期、
情境相似度、来源独立性和人工核验。几何平均有一个实用性质：任何关键短板都不能被
其他高分完全抵消。证据质量再乘当前情境适用性 \(a_i\)，得到质量质量：

\[
m_i=r_i a_i
\]

同一观点的 n 次转载，其独立性因子为 \(1/n\)，因此不能靠转载数量“刷高可信度”。

### 4.3 真冲突与条件差异

先按以下键分组：

\[
g=(\text{币种},\text{期限},\text{市场制度},\text{政策条件})
\]

只在同一组内比较正向质量 \(M_g^+\) 与负向质量 \(M_g^-\)。组内冲突是二元归一化熵：

\[
C_g=-\frac{p_g^+\log p_g^+ + p_g^-\log p_g^-}{\log 2}
\]

各组再按有方向证据质量加权：

\[
C_f=\frac{\sum_g (M_g^++M_g^-)C_g}{\sum_g(M_g^++M_g^-)}
\]

同向时 \(C_f=0\)，同条件下正反各半时 \(C_f=1\)。中性、非线性和条件性观点不再被
错误计入方向熵；不同制度下的相反观点也不再被当成真冲突。

### 4.4 “有冲突”和“没知识”必须分开

证据不足度定义为：

\[
U_f=\frac{1}{1+\sum_i m_i}
\]

没有证据时 \(U_f=1\)，证据质量越多越接近 0。没有证据时冲突度记为缺失值，而不是 0。
否则界面上的“0 冲突”会让人误以为已有大量一致证据。

### 4.5 预测效用与置信区间

知识解释和预测价值是两条独立通道。固定预测器为标准化加 Ridge，按时间做三折：

```text
训练 ≤ 2019，测试 2020
训练 ≤ 2020，测试 2021
训练 ≤ 2021，测试 2022
```

训练尾部按 20 日预测期限隔离，避免标签跨进测试期。单特征增益为：

\[
G_f=\frac{MAE_{\text{零变化基准}}-MAE_f}{MAE_{\text{零变化基准}}}
\]

按月份做 block bootstrap，保留金融时间序列的成簇结构，得到 95% 区间
\([G_f^L,G_f^H]\)。本次修复后，区间与平均值使用相同的“相对增益”单位；旧实现把
绝对误差差值误写成增益区间。

### 4.6 选择性信任状态机

机器不再输出一个含义模糊的综合分数，而是执行硬条件：

| 状态 | 条件 | 动作 |
|---|---|---|
| `AUTO_ACCEPT` | \(G_f^L>0\)，跨折稳定，冲突低、知识足、情境适用 | 自动进入严格信任集 |
| `AUTO_REJECT` | \(G_f^H<0\)，或知识已被明确替代且无有效支持 | 自动拒绝 |
| `HUMAN_REVIEW` | 同条件真冲突，且特征可能有预测影响 | 人只核对观点关系和适用条件 |
| `RESEARCH_ONLY` | 均值可能为正但区间跨 0，或知识不足 | 可做研究消融，不进入自动信任集 |
| `INSUFFICIENT_DATA` | 知识和样本外折都不足 | 补数据后再判断 |

人工只能从支持、矛盾、条件差异、替代、重复、提取错误、不确定中选择，并填写理由与
原文引用。人工接口不能修改预测值、模型权重或跳过样本外验证。

## 5. 增量学习怎样工作

```text
新文档到达
  → 按发布时间做 as-of 检查
  → 抽取原子观点与原文片段
  → 内容去重、标记转载簇
  → 只更新新观点涉及的特征子图
  → 重算冲突度、无知度和适用性
  → 等未来 20 日收益成熟后，才更新预测效用
  → 生成由完整观点内容决定的知识版本号
  → 输出新状态并保留旧版本审计记录
```

旧实现有一个关键缺陷：只有“从未出现过的特征”才会进入重算队列；已有特征收到新研究
反而不会更新。现在所有新增有效观点涉及的特征都会重算。知识版本号也从只读取观点 ID、
方向和状态，改为读取完整结构化内容，因此正文、条件、来源或日期变化都会产生新版本。

## 6. 当前实验结果

### 6.1 受控认知边界压力测试

八种情形包括：一致证据、增益区间跨零、同条件冲突、不同制度条件相反、没有知识、
显著负增益、转载刷屏、只有未来证据。

| 方法 | 状态判断正确率 | 不安全自动采纳 |
|---|---:|---:|
| 只看平均增益正负 | 37.5% | 5 / 8 |
| CIK-RAG 选择性信任 | 100% | 0 / 8 |

这是机制压力测试，只能说明规则按设计工作，不能证明现实文献库上的外部有效性。

### 6.2 真实仓库数据

主实验只用 2017–2022 数据完成选择与评估，没有为新算法读取或调参 2024 留出集。
当前知识侧只有 4 份项目自撰机制说明，抽出 15 条有效观点，全部属于 `internal_note`。
因此严格信任集为空是正确的保守结论：现有证据不足以支持任何特征自动采纳。

当前选择性审计结果为：32 个候选中 1 个自动拒绝、2 个转人工、29 个仅供研究，
机器自动处置覆盖率 3.1%，主动保留或转人工率 96.9%，自动采纳率 0%。这不是算法失败，
而是它识别出“当前知识库无法支撑强结论”。下一步的决定性工作是加入带日期、样本期、
研究方法和原文片段的真实论文与官方报告，再做时间外验证。

具体地，`US_CPI_MoM` 的增益区间整体为负，被自动拒绝；`US_1Y_Treasury_Yield` 与
`WTI_Futures_Price` 存在同条件真冲突，被转入人工复核。严格信任组没有特征，因此系统
明确标记为 `ABSTAIN`，不再给空特征组生成一个容易误读的预测指标。

## 7. 对论文有什么用

这部分可以形成论文的一条独立研究线：

1. **研究问题**：知识冲突、知识缺失和统计不确定性如何共同决定 RAG 的信任边界？
2. **方法贡献**：条件对齐的冲突熵、知识/预测双通道、带拒答的五状态决策、可审计增量更新。
3. **实验贡献**：比较平均分决策与选择性决策的 unsafe accept、coverage、abstention、
   human-review burden，并做去重、条件对齐、置信区间和增量更新消融。
4. **金融价值**：避免把“有经济学故事”直接等同于“有样本外预测价值”，也避免模型在
   制度变化或来源冲突时继续给出过度自信结论。
5. **与原论文衔接**：保留 PA1/PA2/DA/FA 多智能体结构，把 DA 从证据评分器扩展为
   可识别认知边界的选择性决策器；未来还能与原论文提出的跨市场实时数据扩展结合。

论文中应把受控测试、内部笔记实验和真实文献实验分开报告。在完成真实文献库、人工关系
标注一致率和时间外评测之前，不应声称方法优于现有冲突感知 RAG，也不应把当前结果写成
高质量论文已完成。
