# 知识库目录

这个目录是**决策智能体（DA）检索证据的地方**。

## 目录结构

```
knowledge_base/wsl
├── README.md          ← 你正在看的文件
├── notes/             ← 项目自行整理的机制说明（中文）
├── papers/            ← 放你自己的文献，.txt / .md
└── index/             ← 程序自动生成的向量索引，不用手动改
```

## 怎么用

1. 把你要加进来的资料丢进 `notes/` 或 `papers/`（支持 `.md` 和 `.txt`）
2. 跑一次索引构建：
   ```
   .\venv\Scripts\python.exe scripts\build_knowledge_base.py
   ```
3. 之后跑 `main.py` 时 DA 就会检索到这些内容

程序会记录语料的指纹，**只有内容变了才会重建索引**，所以重复跑这个命令很快。

## 重要：`notes/` 里的文档是怎么来的

`notes/` 下的四份说明是**本项目自行整理的**，依据是公开可查的宏观经济与政策事实
（利差、资本流动、央行干预、2018–2024 年中美贸易摩擦的时间线等）。

**它们不是学术文献，也没有引用任何具体论文。** 这样做的原因是：如果拿论文
自己的结论去当证据，再让 DA 依据这些"证据"去证明论文的特征选择是对的，就构成了
循环论证，DA 的评分会失去意义。

如果你想让 DA 的依据更硬，把你的文献（`.md` / `.txt`）放进 `papers/` 即可。

## 支持的文件格式

- `.md` / `.txt` —— 开箱即用
- `.pdf` —— 需要额外装一个库：`.\venv\Scripts\pip.exe install pypdf`
  （当前没装。不装的话 PDF 会被跳过并打印提示，不会报错）

## 不做的事

- 不联网抓取。放进来的就是全部。
- 不编造引用。`notes/` 里的内容凡是涉及具体日期的政策事件，都是可公开查证的；
  凡是机制性的推断，都写明了"通常""一般"这类限定词。
